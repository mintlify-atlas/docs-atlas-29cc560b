pyxctsk is a Python library and command-line tool for working with XCTrack `.xctsk` competition task files used in paragliding and hang gliding. It parses tasks from multiple input formats, converts between them, and implements the FAI Sporting Code S7F §7 optimized distance calculations as an open-source reference.

## What pyxctsk does

pyxctsk implements the complete [XCTrack Competition Interfaces](https://xctrack.org/Competition_Interfaces.html) specification — both task formats, both QR schemes, and all documented fields. All 25 reference tasks generated by tools.xcontest.org round-trip byte-identically.

## Get started in seconds

<Steps>
  <Step title="Install pyxctsk">
    ```bash
    pip install pyxctsk
    ```
    Add `[qr]` for QR image encoding and decoding:
    ```bash
    pip install "pyxctsk[qr]"
    ```
  </Step>
  <Step title="Parse a task file">
    ```python
    from pyxctsk import load_task

    task = load_task("task.xctsk")
    print(f"Task type: {task.task_type}")
    print(f"Turnpoints: {len(task.turnpoints)}")
    ```
  </Step>
  <Step title="Calculate distances">
    ```python
    from pyxctsk import DistanceReport

    report = DistanceReport.from_task(task)
    print(report.as_text())
    # task distance (§7.2)   92.002 km
    # speed section (§7.2)   86.761 km
    # through centres       321.440 km
    ```
  </Step>
  <Step title="Convert to another format">
    ```bash
    pyxctsk convert task.xctsk --format kml -o task.kml
    pyxctsk distances task.xctsk --format text
    ```
  </Step>
</Steps>

## Key features

- **Typed data model** — dataclasses with enum-constrained values; unknown keys preserved verbatim for round-trip fidelity
- **FAI S7F reference implementation** — Ding–Xie–Jiang path optimizer in a localized Transverse Mercator plane, multi-started and converged to ε = 0.1 m
- **Flexible parsing** — auto-detects full JSON, `XCTSK:`/`XCTSKZ:` URL strings, and QR code images from one entry point
- **Lenient by default, strict on demand** — `parse_task(data, strict=True)` rejects structural violations; lenient mode still catches malformed scalars
- **Export to KML and GeoJSON** — optimized route, cylinders, and goal line included
- **CLI** — `pyxctsk convert` and `pyxctsk distances` for shell pipelines and scripting

<Note>
  pyxctsk requires Python 3.11 or later. QR image support (PNG output and reading QR images) requires the `[qr]` extra: `pip install "pyxctsk[qr]"`.
</Note>
